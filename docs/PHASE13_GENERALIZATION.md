# Phase 13 — Generalization Benchmark\n\n## Why this phase exists\n\nA benchmark that only clones the project's full_attack fixture and changes timestamps, noise, or entity values is useful as structural robustness testing, but it is not evidence of broad unseen-attack generalization.\n\nPhase 13 therefore reports two suites separately:\n\n1. Transformation suite — controlled perturbations of the established demo fixture.\n2. Independent campaign suite — attack and benign cases authored directly from scratch without cloning or mutating full_attack, slow_attack, or another attack fixture.\n\nThe second suite is the stronger synthetic generalization test.\n\n> Important evaluation boundary: neither suite proves recall on arbitrary real-world attack campaigns. Public/raw validation and genuinely external datasets remain separate evidence.\n\n## Independent campaign design\n\nThe independent malicious suite deliberately varies:\n\n- users, devices, IPs, applications and resource names;\n- telemetry source names;\n- initial identity evidence (login vs device_enroll);\n- removable-media evidence (usb_mount plus large copy vs large removable copy alone);\n- session identifiers;\n- timing and event spacing;\n- cloud, gateway, endpoint, DLP, database and Linux-audit source labels.\n\nThe independent benign suite contains:\n\n- explicitly authorized removable-media transfers;\n- normal small removable-media copies;\n- authorized network backups;\n- weak suspicious partial activity that must not become a validated incident.\n\nNo independent campaign is generated by cloning the established full_attack fixture.\n\n## Metrics\n\nThe gate measures validated-incident recall and validated false-positive rate separately for each suite.\n\nA hypothesis is not counted as a validated attack. A benign lookalike that produces a campaign hypothesis is therefore still a non-incident outcome, but the exact disposition is retained in the JSON artifact.\n\nRequired gate:\n\n- transformation-suite validated recall = 100%;\n- transformation-suite validated FPR = 0%;\n- independent-suite validated recall = 100%;\n- independent-suite validated FPR = 0%.\n\n## Interpretation\n\nA passing Phase 13 result means the deterministic evidence contract survived both controlled perturbations and a small set of independently authored synthetic campaigns.\n\nIt does not justify the statement '100% recall on unseen attacks in the wild.'\n\nThe correct judge wording is:\n\n> Phase 13 separates fixture transformations from independently authored synthetic campaigns. We use it to test structural generalization, not to claim arbitrary real-world attack recall.\n\n## Loop\n\nBUILD → BREAK → MEASURE → FIX → REGRESSION → GATE\n\nThe benchmark must fail if either suite produces a validated false positive or misses an independently authored malicious campaign.\n
